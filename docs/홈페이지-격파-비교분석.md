심리상담센터 홈페이지라면 3초 안에 이런 게 느껴져야 합니다:

1. "아, 여기 심리상담센터구나"
2. "분위기가 따뜻하고 전문적이네"
3. "어떻게 연락하지?" 또는 "어떤 프로그램이 있지?"

- "어떤 상담을 할 수 있지?"
- "우리 아이가 이런 증상인데 여기서 치료 가능해?"
- "위치가 어디야?"
- "언제까지 영업해?"
- "전화번호가 뭐야?"

```

├── 센터소개

    ├── 공지사항

    └── 자유게시판
```

**총 13페이지. 메뉴 5개. 서브메뉴 최대 4개.**

어떤 정보든 **최대 2클릭**이면 도달.
- "심리치료가 뭔가요?" → 프로그램 → 심리치료란? (2클릭)
- "우리 아이가 ADHD인데..." → 프로그램 → 심리치료의 대상 (2클릭)
- "위치가 어디예요?" → 센터소개 → 찾아오시는길 (2클릭)
- "전화번호?" → 모든 페이지 하단에 있음 (0클릭)

**메뉴에 마우스 올리면 서브메뉴가 깔끔하게 드롭다운.**
각 서브페이지에는 **좌측 서브 내비게이션**이 있어서 같은 카테고리 내 이동이 쉬움.

## 3. 글씨 읽기

### "눈이 편한가? 읽기 쉬운가?"

심리상담센터 홈페이지의 텍스트는 매우 중요합니다.
방문자는 "내 아이의 증상"이나 "내 마음 상태"와 관련된 민감한 내용을 읽고 있기 때문에,
글씨가 작거나 읽기 불편하면 이탈합니다.

---

#### 🌳 푸른나무

- **폰트:** Pretendard (현대적이고 가독성 좋은 한글 폰트)
- **글씨 크기:** 본문 16px (눈에 편안)
- **줄간격:** 넉넉함 (빽빽하지 않음)
- **색상:** 진한 회색/검정 글씨 + 흰 배경 (고대비)
- **포인트 색상:** 숲의 초록색 (#2E7D32 계열) — 자연/치유 이미지
- **제목:** 크고 명확, 단계별로 구분됨
- **본문:** 편안한 서술형. 마치 선생님이 설명해주시는 것 같은 톤

예시 (심리치료 페이지):
```
"사회가 복잡해지고 스트레스의 요인이 많아지고 있는 현대사회에서,
 신체적 건강상태의 질은 갈수록 높아지고 수명도 늘어나고 있지만
 정신적 측면은 그렇지 못한 것이 현실입니다."
```
→ 읽기 쉽고, 공감이 되고, 넉넉한 여백 사이에 배치됨.

점수: **9/10** 👍

---

#### 😊 헬로스마일

- **폰트:** 기본 시스템 폰트 (나눔고딕 등)
- **글씨 크기:** 일부 14px (좀 작음), 일부 16px
- **줄간격:** 페이지마다 다름 (일관성 없음)
- **색상:** 검정 글씨 + 흰 배경 (기본적)
- **포인트 색상:** 주황/빨강 (#FF6600 계열) — 활기차지만 심리센터에 좀 공격적?
- **제목:** 이미지로 된 제목이 많음 (텍스트가 아니라 그림!)
- **본문:** 정보는 있는데 디자인적 여백이 부족

특이사항: **제목이 이미지**
```
"sub_title08.png" ← 이게 "자가진단" 페이지 제목
"sub_title02.png" ← 이게 "커뮤니티/예약" 제목
```
→ 제목을 글자가 아니라 **이미지 파일**로 넣어놓음
→ 검색엔진이 읽을 수 없고 (SEO 최악)
→ 확대하면 깨지고
→ 모바일에서 반응형 불가

점수: **5/10**

### "이 센터 가면 어떤 곳일까?"를 시각적으로 보여주는가?

### 📝 부록 C: "프랜차이즈 홈페이지"의 구조적 한계

이건 헬로스마일이 나빠서가 아니라, **프랜차이즈 홈페이지 구조의 근본적 한계**입니다.

```
프랜차이즈 홈페이지의 딜레마:

    28개 지점의 정보를 → 1개 사이트에 담아야 함
                        ↓
    모든 정보가 "전국 공용"이 됨
                        ↓
    "내가 갈 지점"의 정보를 찾기 어려워짐
                        ↓
    사용자 경험 저하

     vs.

    독립 센터 홈페이지:

    1개 센터의 정보를 → 1개 사이트에 담음
                        ↓
    모든 정보가 "내가 갈 센터" 것
                        ↓
    바로 찾을 수 있음
                        ↓
    사용자 경험 최상
```

**결론:** 헬로스마일의 홈페이지가 나쁜 게 아니라,
**28개 지점을 하나에 넣으려는 구조 자체가 사용자 경험에 불리한 것.**

만약 헬로스마일이 **청주점 전용 홈페이지**를 따로 만들었다면?
→ 훨씬 나은 경험이 됐을 거임.
→ 근데 프랜차이즈 본사 입장에서는 28개 별도 관리가 비효율적이니까 안 하는 것.

**이게 바로 독립센터 홈페이지의 구조적 강점.**
