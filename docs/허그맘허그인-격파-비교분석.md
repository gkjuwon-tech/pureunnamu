| | vs 헬로스마일 | vs 허그맘허그인 |

**규모가 더 큰 상대인데 오히려 점수가 더 낮음.**

49개 지점 → 메뉴가 더 많아지고

더 많은 수익화 시도 → 플로팅 버튼이 더 늘어나고
더 많은 외부 서비스 → 도메인이 6개로 늘어나고

**프랜차이즈가 커지면 커질수록 "내담자 경험"은 반비례로 떨어진다.**

이건 허그맘이 나쁜 회사라서가 아님.
**구조적으로 프랜차이즈 홈페이지는 개별 센터 홈페이지를 이길 수 없음.**

왜?
```
프랜차이즈 홈페이지 = 49개 지점을 1개 사이트에 담아야 함
                     = 모든 정보가 "전국 공용"
                     = "나"에 대한 정보가 0%

개별 센터 홈페이지 = 1개 센터만 다룸  
                     = 모든 정보가 "내가 갈 곳" 전용
                     = "나"에 대한 정보가 100%
```
